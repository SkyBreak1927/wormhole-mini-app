# Laporan critique wormhole-mini (1 November 2026)

Method: dual-agent (A: 8 agen, satu per halaman; B: 1 agen detektor dan bukti browser). Dinilai di `main` (`6d618ab`, setelah Fase 0), desktop 1280 dan HP 375. Skor adalah penilaian model, bukan pengukuran. Konteks: [DESIGN.md](../DESIGN.md).

### P2 (mengganggu, ada jalan keluar)

- Fokus hanya memakai outline bawaan browser. Tidak ada `:focus-visible` yang didefinisikan.
- Placeholder `#757575` di `#1a1a1c` 3,77:1. Border input `#444` ≈1,8:1. Border dropzone `#555` ≈2,6:1. Teks `#666` 3,34:1.
- Marquee: kontras 2,63:1, animasi memakai `left` tanpa `prefers-reduced-motion`, teks Inggris, bersaing dengan aturan satu aksen biru.
- `body{height:100vh}` rapuh saat keyboard HP atau bilah alamat muncul.
- Tidak ada landmark (`main`, `nav`) dan tidak ada `h1`.
- Teks 10–11px (label thumbnail, badge, `.row-note`, bilah pengguna).
- Panel bantuan dan panel bug bisa terbuka bersamaan dan saling menimpa. Bilah pengguna menimpa konten di HP.
- Kisi posisi watermark: 9 kotak kosong tanpa nama.
- Admin: baris banned masih berlampu "Online". Tidak ada cari atau urut. Log menampilkan `ban_user` mentah.

### P3 (poles)

- `<title>` halaman pesan hanya "wormhole-mini".
- Bahasa campur: Download vs unduh, Login vs Daftar, "Copy Link", "Kadaluarsa" (baku: kedaluwarsa).
- Ikon mata hanya berubah opasitas.
- CSS mati (`.forgot-link`, `.step`) dan komentar "quirks mode" usang di `message.css`.
- `.tool-card{display:flex}` merusak niat "ikon di atas label" (sudah ada sebelum refactor).

## Konsistensi lintas halaman

**Konsisten (kekuatan):** satu aksen biru dan latar gelap; token `var(--color-*)` (hanya 1 hex di luar token); radius 6px untuk kontrol; gaya input identik; label 12px `#999`; kolom tunggal terpusat; kode warna status coral, mint, amber; nada bahasa santai dan pesan server yang spesifik.

**Konsisten tetapi buruk (akar masalah):** teks putih di biru atau coral (2,6–2,8:1); elemen klikabel `div` tanpa fokus; status tanpa `aria-live`; tombol di dalam `<a>`; lebar tetap 360px tanpa `border-box` dan tanpa media query; `height:100vh`; font tombol dan input tidak diwarisi (Arial vs `sans-serif`); target sentuh di bawah 44px.

**Tidak konsisten (kandidat konsolidasi):**
- Tombol utama: 10 kombinasi padding (3px 7px sampai 10px 20px), tinggi 24, 27, 31, 33, 36, 37px.
- Tombol sekunder: 3–4 varian. `#logout-btn` dan `#user-bar` terduplikasi di dua file CSS.
- Tautan "kembali": admin biru rata kiri, PDF Tools abu rata tengah.
- Judul: `h2` di sebagian halaman, `h3` di `/d`, `/b`, 404.
- `body{…}` diulang di 7 file CSS. `.pw-toggle` ada dua definisi berbeda.
- 105 penetapan gaya inline di JS dengan warna status di-hardcode.
- Halaman pesan adalah satu-satunya yang keluar dari tema gelap.

## Catatan akurasi dan batas laporan

- DESIGN.md versi awal memuat tiga kesalahan (radius dropzone, "rata kiri" di admin, "ikon di atas label"). Sudah dikoreksi pada PR yang sama dengan berkas ini.
- Detektor menemukan 16 hal di template mentah. 12 temuan warna dan 1 temuan low-contrast adalah false positive (Jinja dipindai tanpa dirender). Yang benar: teks 11px di `batch.html`, ukuran 13px inline di `index.html`, kontras tombol 2,6:1. Di level URL: tombol 2,6:1, placeholder 3,8:1, `.done-label` 4,3:1.
- `/`, `/pdf-tools`, `/admin` tanpa token dialihkan ke `/login`, sehingga detektor hanya memindai halaman login. Untuk ketiganya dipakai pengukuran Playwright dengan API di-mock. `/d/nope` dan `/b/nope` ditolak detektor (HTTP 404).
- Belum teruji: CDN diblokir di harness (QR dan pdf.js tidak termuat). State yang butuh upload sungguhan hanya dinilai lewat mock. Tidak ada uji di perangkat iOS atau Android sungguhan, tidak ada mode terang, viewport 320 hanya state dasar.
- Satu server uji dipakai bersama semua agen, dan token `tok3` habis di tengah sesi. Bukan temuan desain.
